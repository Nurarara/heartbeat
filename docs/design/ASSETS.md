# Artwork and font provenance

Created for Heartbeat on 21 October 2026 using built-in Image Generation:

| File | Purpose and prompt summary |
| --- | --- |
| `docs/design/heartbeat-target.png` | Combined original UI concept: selected midnight glass organism with sparse layout, coral circular action, restrained typography and illustrative atmosphere rail |
| `public/showcase/pulse-organism.png` | Text-free right-aligned smoked-glass looping organism, coral filaments, blue reflections, wet navy floor and left negative space for editable HTML |
| `public/showcase/rain-world.png` | Cinematic rainy riverside viewed from sheltered glasshouse ironwork, distant warm windows and subdued blue-grey light |
| `public/showcase/night-world.png` | Dark coastal pine lookout, faint Milky Way, almost-black ocean and a tiny amber boat |
| `public/showcase/sun-world.png` | Hand-painted summer field, one broad tree and two distant dogs playing with a ball; airy Japanese-film-background style |

Assets were inspected visually and copied into the project. Native tool dimensions are used without stretching, raster editing or baked-in UI. These are promotional/illustrative assets, not private customer images and not live generation evidence. Built-in asset generation did not consume Heartbeat's Cloudflare runtime operating allowance. No artwork or shader was taken from the two reference websites.

Self-hosted fonts were downloaded from the official Google Fonts sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) and [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). Their OFL notices are included under `public/fonts/`. Font hosting is local so page visitors do not need a Google Fonts request.

Earlier `orchard.jpg` and `harbour.jpg` were generic fictional AI diagnostic outputs; they are retained as historical showcase assets but are no longer used in the new landing selectors. Existing bundled art/third-party notices remain applicable. No project-wide open-source license or exclusive rights guarantee is added by this document.
